# Changelog

## 1.0.0 (unreleased)

- Remote-only namespaces: a namespace is a name plus a git URL; the local
  clone is an internal cache.
- `also connect <name> <git-url>` replaces `also set --remote`.
- `also setup` interactive and `--yes` onboarding, plus `install.sh`.
- `adopt` publishes straight to the namespace without a local source directory.
- Installable module path, MIT license, CI matrix and release builds.
